# マネタイズ導線設計書

## 1. ティア構成（4層）

### FREE（無料・サイト入口）

**目的:** 入口体験 + ウイルスループによるユーザー獲得

| 項目 | 仕様 |
|------|------|
| 入力 | 生年月日のみ（任意で出生時刻・出生地・性別） |
| CORE層 | 総合分析（overall）+ 五行バランス + ナクシャトラ概要 |
| HACK層（簡易） | 本日のスコア + 最適時間帯 + 一言ハック |
| FLOW層 | ロック（ブラー） |
| 詳細 | 仕事 / 対人 / 財運 / 健康 はブラー |
| SNSシェア | Canvas APIで生成したシェアカードをダウンロード |
| 的中体験 | 「過去の天中殺年」を1つ提示 |

---

### SHOT（¥100 / 単発課金）

**目的:** 「今日だけ知りたい」層をワンタップで取り込む

| 項目 | 仕様 |
|------|------|
| CORE層 | 全項目アンロック（仕事 / 対人 / 財運 / 健康 + 強み弱み） |
| HACK層 | フル解放（時間帯別最適化チャート + TODOリスト + 軍師メッセージ） |
| 適用範囲 | 紫微斗数 × 27宿 × CORE 全分野 → **本日の行動まで落とし込み** |
| 有効期限 | 当日のみ |
| FLOW層 | ロック |
| アカウント | 不要（ゲスト課金） |

---

### BASIC（¥300 / 月額）

**目的:** 日常的なエンゲージメント（DAU最大化）

| 項目 | 仕様 |
|------|------|
| 含まれる | SHOT 全機能（毎日アンロック） |
| FLOW層 | **月間運勢** = 算命学 × 宿曜占星術。今月＋前後1ヶ月のエネルギーカレンダー |
| 通知（将来） | Web Push APIで毎朝8:00に「今日のハック」を配信 |
| アカウント | 必須（ニックネーム + メール） |

---

### PREMIUM（¥500 / 月額）

**目的:** 高LTV層の資産化（手放せないデータ蓄積）

| 項目 | 仕様 |
|------|------|
| 含まれる | BASIC 全機能 |
| FLOW層 | **年間運勢** = 1〜3年のフル運気カレンダー（月次エネルギー予測） |
| AI対話タスク管理 | 月次で「今月やったこと」を記録 → AI が運勢シナリオを再計算し「次の一手」を提案 |
| Sync Log（運気ログ） | 過去の予測 vs 実際の出来事を AI と振り返る。一致度・的中率の月次サマリー |
| PDF（将来） | 「人生解析レポート」A4 10ページ |
| Calendar連携（将来） | Google Calendar API でハイエネルギー日/注意日を自動登録 |

## 3. ペイウォールUI仕様

### ブラー表示

ロック対象には `--locked` 修飾子クラスを付与する。

```css
/* 共通: result__box / layer-content / vedic-info / energy-calendar すべて対応 */
.result__box--locked .result__box-text,
.layer-content--locked > *,
.energy-calendar--locked,
.todo-list--locked,
.hourly-chart--locked {
  filter: blur(5px);
  user-select: none;
  pointer-events: none;
}

.layer-content--locked {
  position: relative;
}
```

### CTA配置

| 表示位置 | 内容 |
|---------|------|
| CORE 詳細セクションの上 | 「本日のフル鑑定をアンロック ¥100」（FREE のみ） |
| FLOW タブを開いた時 | 「月間運勢を見る ¥300/月」（FREE/SHOTのみ）<br>「年間カレンダーを開く ¥500/月」（BASICのみ） |
| HACK 詳細セクションの上 | 「本日のフル鑑定をアンロック ¥100」（FREE のみ） |

### プラン比較モーダル

CTAボタン押下時に表示。FREE / SHOT / BASIC / PREMIUM を横並びで比較。各プランの選択ボタンは **モック実装** で `localStorage` に書き込み即座に再描画する（決済は後日 Stripe を接続）。

## 4. 継続率最大化の仕掛け

### Sync Log（運気ログ）= PREMIUM の核

過去の AI 予測 + ユーザーが記録した実際の出来事 = 蓄積するほど手放せない「自分の人生データ」。

```
┌─ 2026年4月 ──────────────────┐
│ 4/1 予測:対人運UP            │
│     実際:「新MTGで意気投合」  │
│     一致度:★★★★☆           │
│ 4/3 予測:集中力低下日         │
│     実際:「ミスが多かった」   │
│     一致度:★★★★★           │
│ 4/6 予測:財運好調             │
│     実際:[記録する]           │
│ ─ 月間サマリー ─             │
│ 的中率:78%                   │
│ よく当たった分野:仕事運       │
└──────────────────────────────┘
```

### AI対話タスク管理（PREMIUM）

```
[月初] AI「今月は人脈拡大期。新しい繋がりを増やしましょう」
[月中] ユーザー「先週、業界イベントに参加して名刺を5枚もらった」
       AI「素晴らしいです。次は…そのうち2人にリマインドメールを。
           この行動で、4月後半の財運が +12% に好転する見込みです」
[月末] 月次レビュー → 翌月の運勢シナリオを再計算
```
