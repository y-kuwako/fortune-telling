# マネタイズ導線設計書

## 1. ティア構成

### FREE（無料・集客層）

**目的:** ウイルスループによるユーザー獲得

| 項目 | 仕様 |
|------|------|
| 入力 | 生年月日のみ（3項目） |
| 出力 | 今日のスコア（0-100）+ 五行タイプ + 一行インサイト |
| 所要時間 | 10秒ローディング演出 |
| SNSシェア | Canvas APIで生成したブランドカード画像（navy+gold）を自動生成 |
| 的中体験 | 「過去の転機」を1つ提示（例: 「2023年に大きな環境変化がありませんでしたか？」） |
| 制限 | CORE層の詳細鑑定はブラー表示 |

**シェアカード仕様:**

### BASIC（¥100-300/月）

**目的:** 日常的なエンゲージメント（DAU最大化）

| 項目 | 仕様 |
|------|------|
| CORE層 | フル解析結果（総合/仕事/対人/財運/健康） + 強み弱み |
| HACK層 | デイリーハック（毎朝の戦略ブリーフィング） |
| 通知 | Web Push APIで毎朝8:00に「今日のハック」を配信 |
| UI | 結果ブラー解除、すべてのresult__boxが閲覧可能 |

**毎朝の通知フォーマット:**

```
━━━━━━━━━━━━━━━━
→ 詳細を見る
```

### PREMIUM（¥500/月）

**目的:** 高LTV層の資産化（手放せないデータ蓄積）

| 項目 | 仕様 |
|------|------|
| 全3層 | CORE + FLOW + HACK すべてアンロック |
| FLOW層 | 1-3年の運気カレンダー（月次エネルギー予測） |
| PDF | 「人生解析レポート」A4 10ページ（一生モノ） |
| カレンダー | Google Calendar APIでハイエネルギー日/注意日を自動登録 |
| Sync Log | 過去予測と実際の出来事をAIと振り返る機能 |

## 4. 継続率最大化の仕掛け

### Sync Log（運気ログ）

**コンセプト:** 過去のAI予測 + ユーザーが記録した実際の出来事 = 蓄積するほど手放せない「自分の人生データ」

```
┌─ 2026年4月 ──────────────────┐
│                              │
│ 4/1  予測: 対人運UP          │
│      実際: 「新プロジェクトの │
│            メンバーと意気投合」│
│      一致度: ★★★★☆          │
│                              │
│ 4/3  予測: 集中力低下日       │
│      実際: 「確かにミスが多か │
│            った」             │
│      一致度: ★★★★★          │
│                              │
│ 4/6  予測: 財運好調           │
│      実際: (未記入)           │
│      → [記録する]            │
│                              │
│ ── 月間サマリー ──           │
│ 的中率: 78%                  │
│ 最もよく当たった分野: 仕事運  │
└──────────────────────────────┘
```

### 通知による習慣化

- 毎朝8:00のWeb Push通知で「今日のHACK」を配信
- 3日間通知未開封 → 「今週のハイライト」まとめ通知を送信
- 7日間未アクセス → 「運気が動いています」リエンゲージメント通知

## 5. 技術要件サマリー

| コンポーネント | 技術 | 優先度 |
|-------------|------|--------|
| 認証 | LINE Login SDK + メール/パスワード | P0 |
| 決済 | Stripe Checkout (JPY, monthly) | P0 |
| ペイウォール | CSS blur + JS課金状態チェック | P0 |
| Web Push | Service Worker + Push API | P1 |
| シェア画像 | HTML Canvas → Blob → download/share | P1 |
| PDF生成 | サーバーサイド (Puppeteer or html-pdf) | P2 |
| Calendar連携 | Google Calendar API OAuth2 | P2 |
| Sync Log | DB (Firestore or Supabase) + REST API | P2 |
